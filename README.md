# Owners API Endpoints

| Method | Endpoint              | Description                         |
|--------|----------------------|-------------------------------------|
| GET    | `/api/owners`         | Retrieves all registered Owners     |
| GET    | `/api/owners/{id}`    | Retrieves a specific Owner by ID    |
| POST   | `/api/owners`         | Creates a new Owner                 |
| PUT    | `/api/owners/{id}`    | Updates an existing Owner           |
| DELETE | `/api/owners/{id}`    | Deletes an Owner by ID              |
